                   Bank Overview
                   =============

The linker layout below is configuration-independent. Actual RAM use and free
space are emitted from the MPLINK map of each build by tools/build_hwos.ps1;
inspect its `Memory budget report` and build/build-info.txt rather than keeping
static figures here.

Bank        Use                                             Start    End  Size
-------------------------------------------------------------------------------
access RAM  ASM/C/math-lib scratch data (shared)            0x000  0x05F    96
0           ASM (ISR) vars                                  0x060  0x0FF   160
1           ASM vars "common" + local1/local2/local3        0x100  0x1FF   256
2           buffer                                          0x200  0x2FF   256
3           ASM / C shared vars                             0x300  0x3FF   256
4           ASM / C shared vars                             0x400  0x4FF   256
5           C vars p2_deco                                  0x500  0x5FF   256
6           C vars p2_deco                                  0x600  0x6FF   256
7           tissue pressures "real"                         0x700  0x7FF   256
8           tissue pressures "sim"                          0x800  0x8FF   256
9           C vars compass and compass_calib                 0x900  0x9FF   256
10          ASM vars "common2"                              0xA00  0xAFF   256
11          ASM / C shared vars (buffer2, backtracking)     0xB00  0xBFF   256
12          tissue pressures "vault"                        0xC00  0xCFF   256
13          C stack                                         0xD00  0xDFF   256
14          options table                                   0xE00  0xEFF   256
15          Linker allocation range; F16-F5F are device SFRs  0xF00  0xF5F    96

Only 0xF00-0xF15 of bank 15 is usable GPR. The PIC18F87K22 device include maps
0xF16-0xF5F as SFRs, which the build report marks protected even though MPLINK
requires its SFR sections to fit in the grp15 linker range. accesssfr (0xF60-0xFFF,
160 bytes) is also PROTECTED C18 SFR space, not a GPR bank.

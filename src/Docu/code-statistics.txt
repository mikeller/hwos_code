Build Memory Reports
====================

Memory usage is configuration- and toolchain-dependent. After each successful
link, `tools/build_hwos.ps1` derives flash and RAM use from `build/hwos.map` and
writes the result to the console and `build/build-info.txt`. Use the
`flash_budget_*`, `flash_block_<n>_*`, and `ram_bank_<n>_*` keys for the exact
source commit and selected configuration rather than static estimates.

The global version selection and feature settings are documented in
`src/configuration.inc`.

Historical MPLAB X setup notes
==============================

This file predates the reproducible command-line build and is retained only as
historical context. It is incomplete and its linker-script name is stale.

For a Windows build, use the official MPLAB C18 v3.47 installation and follow
`doc/building.md`; run `tools/build_hwos.ps1`. It selects PIC18F87K22, compiles
the top-level `.asm` and `.c` sources, and links `src/18F87K22_hwos.lkr`.

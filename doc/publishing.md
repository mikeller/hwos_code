# Publishing this mirror

## What this repository is

`mikeller/hwos_code` on GitHub is a Git mirror and working fork of the
heinrichs weikamp hwOS firmware source, which is maintained upstream in
Mercurial at `https://code.heinrichsweikamp.com/public/hwos_code`. It is
**not** an official heinrichs weikamp distribution channel, and publishing it
here asserts nothing beyond what upstream already publishes. The latest
Mercurial revision imported into this mirror is recorded in
`base_upstream_revision.txt`, updated automatically by `sync_from_hg.sh`.

## Branch model

| Branch | Role |
| --- | --- |
| `master` | Faithful `hg-fast-export` mirror of the hg `default` branch. Written only by `sync_from_hg.sh`; never hand-edited. |
| `development` | Default branch on GitHub. `master` plus this fork's build enablement and other changes not yet accepted upstream. |
| `new_screen_layout`, `ClaudeDive_Translations`, `compass3-3.01-orphan` | Mirrors of the other hg branches and of the one orphan head (see `README.md`). Written only by `sync_from_hg.sh`; published. |
| `feat/...`, `build/...`, `docs/...`, `fix/...` | Short-lived work branches, merged into `development` by pull request. |

All of the above are published. There is no separate orphan publication
snapshot: `github/main`, published in the past as `main`, is **retired** and
must not be described anywhere as the publication branch or as this
repository's public face. `development` is both the GitHub default branch and
the publication branch.

This matches the model used by `mikeller/ostc4`, which likewise publishes
`master` alongside `development` and uses `development` as its GitHub default
branch.

### The additions-only invariant

`git diff master development` must consist of additions and genuine source
changes only, with exactly one named deletion: `src/clib.lib`. `development`
is allowed to add build enablement and documentation that `master` does not
have, and to change source in ways not yet accepted upstream, but it must not
otherwise drop files that `master` carries. Re-check this invariant with
`git diff --name-status master development` whenever `development` changes
relative to `master`.

## Binary policy

- Binaries that exist in the upstream Mercurial repository are kept and
  published as they are. Upstream chose to publish them; mirroring that
  choice asserts nothing additional about rights to them.
- Binaries generated by this fork's own build tooling are never committed.
  `build/` is ignored in its entirety (see `.gitignore`), and
  `tools/*.hex` not already tracked from upstream is likewise ignored.
- One carve-out: `hg-fast-export_metadata.zip`, committed at the repository
  root, is hg-to-git import state (not build output), and is committed to
  mirror the equivalent practice in `mikeller/ostc4`.
- One named exception to "upstream binaries are kept": `src/clib.lib`,
  Microchip's precompiled MPLAB C18 runtime library, stays excluded from this
  mirror. This is **not** a licensing argument; it rests on build evidence
  instead:
  1. `tools/build_hwos.ps1` requires `clib.lib` and `p18F87K22.lib` in the
     C18 **installation** and throws if either is absent there.
  2. `tools/build_hwos.ps1` runs MPLINK with its working directory set to
     the C18 installation's `lib` directory, so the linker script's
     `LIBPATH .` resolves to the installation, not to `src/`.
  3. The repository only ever contained `clib.lib`, never
     `p18F87K22.lib`, although `src/18F87K22_hwos.lkr` declares `FILES`
     for both.
  4. Nothing anywhere in the repository references `src/clib.lib`.

  In short: `src/clib.lib` is not a build input, so it is excluded on
  "we do not ship what we do not use" grounds.

### Microchip content that stays

- `src/P18F87K22.INC` is Microchip's device header and **is** used:
  `src/hwos.inc` includes `p18f87k22.inc`, and MPASM runs with its working
  directory set to `src/`. It is kept deliberately, because pinning the
  device header is a reproducibility and safety property, not an oversight.
- `39960d.pdf` (the Microchip PIC18F87K22 datasheet) is kept for the same
  reason.

## Licensing position

This repository has no repository-wide licence and no `LICENSE` file.
File-level notices govern instead (see `NOTICE.md`):

- 82 source files are marked "all rights reserved" by heinrichs weikamp and
  JD Gascuel.
- `src/p2_deco.c`, `src/p2_definitions.h`, and `src/shared_definitions.h` are
  GPLv3-or-later.
- `src/P18F87K22.INC` is Microchip's.

Do not add a licence, and do not alter any file-level copyright notice.
Publishing this mirror does not change, broaden, or resolve this position; it
only makes the existing source visible under its existing notices.

## Safety position

A successful build proves only that the C18 toolchain linked an image. It
does not validate device behaviour. Packaged OSTC Companion containers carry
`UNVALIDATED` in their filename and remain test containers until they have
passed the vendor-approved hardware and recovery procedure. See
[`building.md`](building.md) and [`firmware-packaging.md`](firmware-packaging.md)
for the build and packaging detail behind this position.
